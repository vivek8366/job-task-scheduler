Problem Statement

Given a set of jobs where each job has a deadline and profit, schedule the jobs within their available time slots such that the total profit is maximized. Each job takes one unit of time and must be completed before or on its deadline.

Key Features
Greedy Job Sequencing
Sorts jobs based on profit.
Assigns each job to the latest available slot before its deadline.
Maximizes achievable profit.
Brute-Force Comparison
Tests all possible job combinations for small datasets.
Compares the brute-force optimal result with the greedy result.
Sorting-Based Optimization
Demonstrates how sorting simplifies the greedy decision-making process.
Time-Slot Scheduling
Tracks available time slots efficiently.
Prevents conflicting job assignments.
C++ STL
Uses vectors, sorting, priority queues, and other standard data structures
